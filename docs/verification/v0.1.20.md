# v0.1.20 验证入口与范围

基线为已发布 v0.1.19 的固定源码 972742cf3ae603baa33ac4c312e3c40b53a8b9ca。

## 可重复验证入口
- Python：`pytest -q`。新增 core 交接选项、不可变预览快照、三向原子处理、真实局部干涉与整桌逐角处理测试。先在旧实现观察失败，再实现并运行全套。
- 官方 Blender：`bash tools/verify_joint_editor.sh BLENDER OUT`。本机原生属性对话框、GPU 局部预览、两档 UI 缩放、真实键鼠确认/取消/撤销/重做、新进程保存重开。
- 原有回归：`verify_multi_slot.sh`、`verify_copy_wheel.sh`、`verify_panel_startup.sh`、`verify_console_joints.sh`。覆盖混合吸附、槽轨多选、工程复制、中键盘、空场景面板、原始交接和工作区等。
- 覆盖安装：`python tools/verify_joint_editor_upgrade.py BLENDER OLD_ZIP NEW_ZIP OUT`。隔离配置中安装 0.1.19，保存真实 ON_SLOT 工程，再直接安装 0.1.20 并重开，不手工卸载，不改用户真实配置。
- 编译、同环境重复构建逐字节比较、官方 `extension validate`，远程固定提交运行全部门禁。
- 发布：仅将验证通过的固定提交写入既有 Preview；部署后获取公网 index 和 ZIP，核对版本/字节数/SHA-256；交付 ZIP 必须与运行测试包一致。

## 发现并修复的问题
1. 原生对话框确认会再次调用 poll。不能把“已有预览”一概判为不可执行，否则确认跳过 execute 而残留预览。执行阶段保留场景/数据/选择/目录新鲜度检查并负责清理。
2. UI 1.5 时原生弹窗与另一侧 N 栏会遮住预览。临时收起另一视窗 N 栏，关闭后精确恢复；槽位小窗和底部静态信息在交接预览期间暂隐藏。
3. 对整张桌架做全关联组件碰撞扫描，会误将尚未处理的远端角点作为当前失败。改为已配置的局部交接相关对；加入四角顺序处理和返回第一角换方案的回归。
4. 原生属性弹窗中的右键不是本插件操作盘的右键语义；交接编辑器采用原生取消按钮 / Esc，不虚称右键任意处一定取消。

## 审查及边界
没有独立审查代理可用；执行同一会话全差异审查及可执行回归，不冒称独立审查。
运行检查混合真实键鼠、命令调用和数据断言，不等于同数量独立人工端到端故事。
只做局部矩形外廓、正交平端几何。通过不表示连接件、供应商加工、安装工具空间或结构安全已确认。
本地 Python 与远程 Python/SQLite 版本可能导致生成目录文件二进制头不同；可重复性限定同环境，交付远程测试/发布一致的 ZIP。
具体固定提交、远程门禁、报告数量和发布哈希在交付包 VERIFICATION.md 中记录；未通过的门禁不得写成通过。
