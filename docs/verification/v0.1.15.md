## Review and limits
Inline whole-diff review; no independent reviewer agent was available. Checks mix real mouse/key events, Blender operators and data assertions, not hundreds of independent mouse-only stories. Scaling tests simulate Blender display scaling, not every Windows OS monitor/DPI arrangement. Very narrow/short viewports intentionally hide the inset and have no input hit area. Large assemblies and third-party add-ons remain user acceptance boundaries.
No modifications to authoritative member/node/association schema. New UI state is a display preference or ephemeral hover/target state. Inspection, target pinning and relation creation remain distinct. Design-line length is not manufacturing cut length. Creating more complex joint/cutback behavior is outside this release.
