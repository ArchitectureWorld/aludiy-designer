# v0.1.13 — 双视窗进入与投影同步修复

用户已授权开发完成后直接发布。基线：f2cdb12e04ddc9457477fcc11ffe9175957885c3（0.1.12）。本轮反馈中除工作区问题外其余内容仅记为基本体验通过。

## 根因与约束
真实 Blender 5.2.2 复现：workspace.duplicate 分配副本后延迟切换；立即重命名 context.workspace 会改动原 Layout，后续又进入 Layout.001。分屏同样需要等待布局计算完成。旧配置强制左 ORTHO / 右 PERSP，复制与变更检测只含转向/中心/距离，无法同步投影或焦距。

## 验收目标
1. 原 Layout 身份、名称、编辑器数量及视角不变；只新建一个 ALU DIY，自动进入。重复点击或从原 Layout 返回时复用工作区，不累积分屏。
2. 新建工作区继承原三维视角及投影；既有工作区重设时以右侧实体视图为准。不把线图强制为正交，也不把用户选择的正交强制为透视。
3. FULL 同步方向、中心、距离、透视/正交/相机投影、焦距、裁剪与相机视图框。ORIENTATION 保留独立缩放；OFF 保持独立。单独改变投影/焦距也能触发同步。
4. 切回工作区、重新启用插件、载入工程时，空闲视图也对齐。延迟请求在停用/载入/关闭窗口后安全清理。
5. 保持工程数据、线/体隔离、画线、G、手动关联、换型、截面和槽位检查。旧 Layout.001 可能包含用户布局，不自动删除。

## 实施顺序
RED 单元和真实 GUI 复现 → 修复创建时序与全视角状态 → 透视/正交两组初始化、重复进入、投影切换、停用重启与新进程重开 → 全量保留功能回归 → 完整提交 → Preview 固定测试 SHA → 公网索引与 ZIP 校验后交付。
本版为工作区稳定性修正，不引入槽轨附着、自动退让、数据格式变更或右窗画线。
