# v0.1.12 — 型材换型、截面朝向与槽位检查

用户已授权补齐并发布。基线 31f99ee4c434119f54b8a4566f49f2fbacf1a4b3（0.1.11）。先前仅保存了截图，本轮从已验证源码归档恢复开发，不把旧截图视为完成证据。

## 验收目标
- 多选型材一次换型，设计线、节点坐标、既有关联不变，活动项和完整选择集保留。
- 截面绕本杆设计轴 ±90° 或指定角度旋转；不是 Blender 全局 R，不旋转或平移设计轴线。多选相对旋转各自保留原角度差；绝对角度统一设置。
- 单根活动型材有二维截面示意与稳定槽 ID；槽位按钮仅检查、高亮其沿杆位置，不吸附、不关联、不宣称制造级接口验证。
- 使用现有五种测试截面；真实供应商 DXF、槽轨附着、节点退让仍后置。
- 事务失败回滚、Undo/Redo、JSON/保存重开、BOX/细节切换、原有画线/移动/手动关联持续回归。
- 延用既有 schema，无需数据升级；仍仅在线图启动画线（用户明确不优先要求右窗画线）。

## 实施顺序
1. 核心批量参数更新与槽轨坐标计算：先失败测试，再实现。
2. 专用侧栏命令、保留选择的事务、二维截面/三维槽轨检查显示。
3. Blender 5.2.2 官方程序实际回归（新增与全部保留检查）；构建确定性校验。
4. 完整源码一次校验后提交，Preview 固定测试 SHA 发布，公网索引/ZIP 校验后交付。

## 注意
轮廓为语义 LOD 示意，不是完整加工截面。换型保留现有设计轴线关联，不表示槽位或连接件能无条件互换。当前 roll=0 的参照沿用旧版局部坐标规则，不在本版改变工程几何定义。
