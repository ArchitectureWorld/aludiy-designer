# v0.1.14 — 槽轨定位与显式附着

基线：已发布 0.1.13 (286b580ad1fc72a866725e9ad06015264ef6ef28)。用户授权下一步开发并发布，继续已讨论的槽轨定位与附着，不扩展至退让/连接件。

## 验收契约
1. 在已有槽位检查器选具体接口并设为定位目标。目标独立于当前移动对象；双视窗持续显示 Member + Interface，明确只定位。G 和画线共用目标槽轨候选；Ctrl、数值和轴/平面锁定规则保留。
2. 位置摆准后，多选杆件/节点点击创建关联；可对已指定的目标槽轨创建，唯一的几何接合也可自动识别，歧义必须提示而不是猜。绝不因吸附自动绑定。
3. ON_SLOT 记录主杆、稳定接口ID、相对站位以及带profile/revision身份的不可变接口位置快照。目录仍是类型源；快照确保核心/离线工程在无bpy、无全局目录状态下可验算。接口不按2020/2040尺寸猜测。加载时检查目录身份/接口几何一致性；失配拒绝，不偷偷改配。
4. 主杆平移、改长、截面roll变化驱动附着端；远端不被擅自移走。沿用相对站位（0.5为中点）。从属端独立移动需先解除，支持撤销/重做/保存重开。循环、多主杆、自关联、零长度均拒绝。
5. 有槽轨附着的主杆换型先阻止，要求明确解除并重选槽；不按相同槽ID猜兼容。旧轴线/共享节点关系保持。
6. 首次创建ON_SLOT升级schema 0.3.0。旧工程继续读，新工程旧插件不支持，不得降级覆盖。槽口几何是测试目录的语义中心线，非供应商制造级槽形，不声称物理接头适配。
7. 双视窗进入/投影同步回归；左侧起画约束保持。完整测试、原位更新验证、上传源码、CI真Blender验证、Preview公网索引/ZIP验证后交付。可视化看板同时更新。

## 顺序
- 核心：新关系结构/快照校验/图传播/换型保护，TDD。
- 几何：有限槽轨候选/单位精度/锁定/候选ID，TDD。
- Blender：目标固定与清除、G/画线、统一创建/解除入口及双窗标识，运行验证。
- 复核与发布：回归现有5套GUI+工作区、保存重开、升级；版本固定到已验证源码，不合并父分支。
