# v0.1.9 实施记录：端点吸附与重新连接

用户已确认的本轮范围：G 默认吸附；Ctrl 临时自由移动；明确目标确认后重新建立关联；地面可吸附但仅定位；保留 KEEP / DETACH 与一次撤销。

## 复用评估

QuickSnap（https://github.com/JulienHeijmans/quicksnap，MIT）已有源点/目标点及候选反馈交互，但以 Blender 对象/网格为操作对象，不能代替本项目的共享工程 Node 事务。参考其交互原则，不引入依赖、不复制其源码。Blender 自带 view3d_utils 与现有 G modal 已满足投影/事件/锁轴能力，复用已有工程核心最小扩展。

## 实施顺序

1. 新增无 bpy 的 snapping.py：可测试候选、轴限制、地面候选、原子重新连接。先运行缺失能力测试（16 fail），再实现到通过。
2. G 统一处理候选与明确目标：最近源端点、节点优先、Ctrl press/release 即时切换、Tab 候选、数字位移优先、仅确认提交。
3. N 面板增加“连接到目标…”和地面设置，双方视窗显示目标 ID 与“连接/仅定位”语义。
4. 真实 Blender 5.2.2 后台与 X11 键鼠检查；保存后新进程重开；旧 G 和样例安全回归。
5. 版本 0.1.9，更新看板、验收说明；测试通过再发布 Preview，独立于 PR 合并。

## 重要决策

- 无 schema 升级，连接复用目标 Node ID；只清理本次被取代且无引用的源节点。
- KEEP 移动并重接公共节点所有关联；DETACH 只重接显式选定的杆端；Ctrl 仅控制新的吸附/连接。
- 数字位移不被吸附改写；只在到达容差 0.0001mm 内时允许形成连接。
- 拖动预览不销毁/隐藏选中源对象。Blender 隐藏会取消选择；保留源缓存，在确认时统一重建。
- “连接到目标”不能污染下一次普通 G；该临时选项 SKIP_SAVE 且普通 G keymap 明确设 false。
- 无独立 reviewer 工具，使用自审和可执行回归，不声称进行了独立审查。

## 后续而非本轮

画线与 G 的中点、垂足、轴线候选共享；目标主杆 station/槽轨持久附着；参考面；L/T 节点退让。第一稿只交付完整可解释的端点连接闭环，避免位置重合冒充中部关联。
