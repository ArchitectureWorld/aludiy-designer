# v0.1.11 · 画线与移动统一工程吸附

基线：已发布 0.1.10 / 9f1d443c5dc50af0fd9f1f9f7060d7c7b4de0113。
用户最新反馈：基本测试无问题，授权推进下一步。完成原工程吸附计划的剩余画线接入，不跳到新商城/AI系统。

## 范围和规则
- 复用核心工程候选，不安装 QuickSnap。参考其源/目标提示与中点交互（官方项目 https://github.com/JulienHeijmans/quicksnap 和官方扩展页 https://extensions.blender.org/add-ons/quicksnap/）；其网格操作不能替代工程数据，未复制第三方源码。不要沿用旧文档未经核实的 MIT 许可断言。
- 画线与 G 统一节点/端点、中点、起点到杆身的垂足、杆身设计轴线候选，保持毫米双精度。
- 像素阈值与 X/Y/Z、Shift+轴的显式平面限制同生效。工作平面仅作为没有吸附时的自由定位面，首点可吸附任意标高，保留既有空间画线能力。
- Ctrl 临时关闭吸附，松开恢复；Tab/Shift+Tab 切换候选，反馈目标 ID、类型、距杆起端的距离/全长与仅定位语义。
- 数字长度与 @长度<角度优先，目标提示不得冒充并未实际到达的点；无效输入不可提交。
- 新线默认独立；不自动绑定、不切断主杆，不改变旧关联或 0.2.0 schema。
- 确认每段后保存该段；Esc/右键结束并取消尚未确认的一段；结束后的 Ctrl+Z 撤销本轮连续画线（沿用当前事务粒度）。
- 双窗反馈/结果同步。排除 UI 点选、导航、其他区域事件误生成线。

## 任务与验证
1. 核心候选聚合、垂足与双精度长度解析：先失败用例，后实现；测试轴/平面、共线退化、精确输入、候选优先级和无数据修改。
2. 两个操作调用同一候选接口；画线 Ctrl/Tab/数字输入与跨平面目标；源/目标提示、双窗标记；静态约束 + 真实后台操作。
3. 真实 Blender 5.2.2/X11：中点起画→Z精确立柱→独立节点→手动附着；Ctrl/Tab、取消/撤销/重开；原多选、关联、移动、样例安全回归。
4. 更新版本/验收/可视化看板；远程分支与 Runtime CI；通过后发布 Preview 并校验公网 ZIP，不要求先 ZIP 人工验收。
