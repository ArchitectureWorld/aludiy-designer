# v0.1.9 verification record

This record describes executed local checks, not blanket user acceptance.

- Base: published v0.1.8 / 3c6e5bc2e745fe8c1d63608d2d29060eadb6fb40.
- Official Blender 5.2.2 LTS Linux archive verified against its SHA-256 list; actual runtime build d13f752e3b9c.
- 155 Python tests passed after the final code changes.
- New core tests were first run without the new module (16 expected failures), then passed with the implementation.
- Real Blender backend tests first failed on missing G reconnection properties, then passed. A redundant zero-displacement detach/return regression exposed a sticky DETACH state and was fixed and re-run.
- Real X11/XTest mouse/keyboard checks: 32 snap/reconnect, 28 previous movement, 16 previous sample-safety checks passed in the final local run.
- New-process reopen comparisons passed for reconnected, detached-movement and sample-insertion projects.
- Official isolated local extension repository install 0.1.8 -> reinstall 0.1.9 without uninstall succeeded; a saved 0.1.8 project's exact engineering JSON was preserved.
- Two builds in the same environment were byte-identical; official Extension TOML/ZIP validation and server index generation succeeded.
- Progress HTML was rendered with Chromium; status filter and keyword search were exercised.

## Review findings resolved

A selected source cannot be hidden during reconnect preview: Blender hiding clears selection. Keep its display cache alive at the candidate target until confirmation, restore it on cancel, and rebuild only on commit.

The connect-target picker must not become the remembered default of the next G invocation. Use SKIP_SAVE and an explicit false value in the normal G keymap and button.

The XTest test harness must use the case-sensitive Tab keysym, not `tab`. Production Tab handling was verified by a real key event after correcting the test harness.

## Release gate

Run Snap Reconnect Runtime Verification on the immutable source commit; only then point Preview at that commit. Publisher must verify the public index, downloadable ZIP size and SHA-256. CI evidence is separate from this local record.

Windows, non-default DPI, third-party keymap conflicts and large-project performance remain user acceptance. Mid-rail/slot attachment, arbitrary surface snap and manufacturing/structural validation are not included. No independent reviewer agent was available; this work used self-review plus executable tests.
