# v0.1.6-alpha 发布说明

本版把 AluDIY 从“能精确画”推进到“能精确改”。

## 新增

- 节点 XYZ 精确编辑；
- 型材起点／终点 XYZ 精确编辑；
- 型材 XYZ 增量平移；
- 共享节点修改传播；
- 受影响型材 revision 同步更新；
- 选中型材临时参考尺寸；
- 选中节点坐标反馈；
- GitHub Pages 远程扩展仓库发布链路。

## 保持不变

- 工程数据仍以毫米为单位；
- 线和实体仍是同一 Member 的两种缓存表达；
- `Ctrl + Shift + Delete` 为工程删除；
- Blender 原生删除快捷键不被覆盖；
- 项目 schema 仍为 `0.1.0`，无需迁移。

## 已知限制

- 参考尺寸目前不持久化，也不能直接点击编辑；
- 节点拖动 Gizmo、完整吸附和约束冲突求解后续实现；
- 远程仓库首次发布需要标签触发工作流。
