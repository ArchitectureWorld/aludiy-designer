# v0.1.20-alpha — 交接系统第一阶段：可视化方案编辑

## 更新
先保存工程副本。原仓库 Refresh Remote → AluDIY Designer → Update，确认 0.1.20-alpha。无需卸载、清空工程或重新配置更新源。

## 整体路线
1. **本版：交接方案编辑。** L/T 及轴线两两垂直、三个设计端点重合的三向角点；主杆方案、局部预览、间隙、参考尺寸、明确提交/取消。
2. **尺寸控制。** 区分固定轴线、外尺寸、净空；明确对齐基准与更换截面后处理，不能静默改变设计意图。
3. **标准连接件。** 先验证一套供应商型材/槽/紧固件组合，再扩展配件库；带适配和必要加工数据。
4. **装配检查。** 构件/配件碰撞、安装次序、工具空间与槽内插入路径；不把几何检查当承载校核。
5. **加工与输出。** 加工参考、BOM、下料、节点模板和批量处理；各项输出与模型同源、可追溯。

## 第一阶段入口
在对象模式选中同一交接的 **2 或 3 根完整型材**，不要只选端点。
中键操作盘 → 交接处理 → **预览 / 切换 L·T·三向方案**。
也可 N → AluDIY → 交接方案与端面处理 → 同名按钮。

最后选中杆件只用于初始建议，不决定最终接法。对话框 A/B/C 明确标注对应杆号，单击可切换。T 形中无合法接合端的反向方案会置灰并解释原因。

## 编辑器怎样使用
- **金色是贯通主杆**，其他颜色为支杆；模型区左下方显示真实计算的局部矩形外廓预览，可切轴测、俯视、正视、侧视。
- 端面间隙默认毫米，支持 2mm / 0.002m 和已有单位算式规则。每次从原工程快照重算，不反复扣减。
- “对比修改前”比较打开编辑器前的状态，不等同于把全工程加工清空。
- 信息区分别显示设计线长度、实体参考长度、起/终端退让，以及所选构件组的世界 XYZ 外包络和低/高边界位移。
- **设计线、节点和位置关联始终不因交接处理而移动。** 因主杆实体补长，外边界可能变化；第一阶段不提供“保持家具外宽不变”的约束。
- 点击“应用交接方案”才写入工程；**取消按钮或 Esc** 零改动，确认后一次 Ctrl+Z 撤销整组处理，重做恢复。再次打开原选区可以换方案或间隙。
- 预览期间暂时收起另一三维视窗的 N 栏，让局部预览可见；关闭后恢复原状态。预览不创建临时模型对象，不写工程 JSON 或改缓存网格。

## 三向角点与整张桌架
三向首版仅支持三个设计端点重合、轴线两两垂直、相容矩形外廓的平端处理。三种主杆方案分别计算两根支杆收头，同时检查局部主支杆/支杆间外廓相交；不合法方案不可提交。
不是“所有三根杆件都能交接”：错位三向、斜接、斜切、45°拼角不在本版范围。

可按桌架四个角逐个配置。修改当前选区内的交接规则，保留通向其他杆件的规则和另一端加工；如果当前杆端已被未选中的主杆占用，会明确拒绝冲突，不偷偷覆盖。
局部外廓检查只针对已配置的交接相关对象，不将尚未处理的远处桌角视为当前编辑失败；也不代表全场景碰撞检查。

## 测试模型
`桌架交接第一阶段测试.blend`：1200×600 的设计轴线平面、750 高设计立柱，8 根 2020 测试型材，初始没有加工规则。设计轴线跨度不是实体家具外宽。
四角选择分别为：L1+X1+Y1、L2+X1+Y2、L3+X2+Y2、L4+X2+Y1。初始选中第一角，直接打开新编辑器。
`桌架四角已处理示例.blend`：四角均选对应立柱贯通，间隙 0；可直接重新选第一角切换方案，检查其他角保留。

## 三项体验验收
1. 第一角选三根 → 对比 A/B/C → 间隙 2 → 对比修改前 → 取消：几何和工程数据不变。再确认，一次撤销可恢复。
2. 确认立柱贯通后处理另外三角，再回第一角换主杆或改间隙：不累扣长度、不丢另一端或其他角的加工规则，设计线不动。
3. 两根 L 接可以互换主杆，T 接明确保留贯通立柱；不合法三向或过大间隙显示原因、不能提交。保存重开保持结果。

## 兼容和边界
本版不增加数据格式。首次使用交接规则仍沿用已有 schema 0.4.0；请勿用 0.1.15 或更旧插件覆盖保存 0.4 工程。
已有吸附、多选槽轨、手动关系、复制、中键盘和空场景面板继续保留。原二杆快速交接入口保留，以避免破坏旧操作；新体验请使用“预览 / 切换”入口。
局部预览是实算的矩形外廓，不含供应商凹槽细节、真实角码或连接件。外廓检查保守，不做槽内嵌套、工具可达性或结构承载确认。暂不支持任意斜接、错位三向和自动选配连接件。
Blender 5.2.2 Linux 运行回归不等于所有 Windows、显示缩放、其他插件、多操作系统窗口及大工程均已验收；仍需本机体验。
