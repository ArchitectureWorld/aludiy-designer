# v0.1.18-alpha — 工程复制 / 中键操作盘 / 删除目标清理

## 更新
先保存工程副本。原仓库 Refresh Remote → AluDIY Designer → Update，确认面板0.1.18-alpha。无需卸载、清空工程或重新设置仓库。普通Blender对象仍使用原生操作。

## 1. 删除槽轨主杆后立即可以移动
工程删除（操作盘“删除…”或现有工程删除按钮/快捷键）会一并清理这个主杆的工程关联、交接规则和失效的槽轨吸附目标，不删除其他有效关系。
旧工程已经残留“目标槽轨的主杆不存在”时，再进入G或画线会自动清除这个不存在主杆的临时目标并恢复普通吸附，不必先手动停止定位。
只对“主杆确已不存在”的临时目标回退。目录版本、有效主杆槽位不兼容或工程数据错误仍需明确处理，不静默改配/清空工程。
原生X/Delete仍不是工程删除；不要只删除三维缓存来代替删除杆件。重建视图依旧以工程数据为准。

## 2. Shift+D工程复制
在ALU DIY双视窗、对象模式下，选完整的一根或多根型材 → Shift+D → 移动鼠标/锁轴/输入距离 → 左键或Enter确认。
- 副本使用新的杆件、节点、关联和交接ID；规格、截面朝向保留，不与原件共用端点。
- 选区内部的共享节点、重合关联、杆身/槽轨附着和L/T规则按新ID对应。没有选中的杆件不会被暗中一起复制。
- 跨越选区边界的关联/交接不继承，状态信息显示未继承数量。只复制横梁而不选主杆时，副本不会继续绑定原主杆。
- 摆放共用G的吸附、Ctrl临时自由移动、X/Y/Z锁轴、数值输入、Tab候选切换。吸附仍只定位，不自动关联。
- Esc或右键取消整个复制，不留下重叠副本；确认后一次Ctrl+Z撤销“复制+摆放”，重做恢复一次。直接Enter在原位确认会有意创建独立重叠副本。
- 单独选端点/独立节点不生成孤立型材副本。普通对象继续原生Shift+D；普通对象混入工程选择时拒绝复制且不改变任何对象。
旧版原生复制产生的缓存对象不会自动转换为工程杆件，请从工程杆件重新复制。

## 3. 中键操作盘
在ALU DIY模型区轻点滚轮中键，在鼠标位置弹出；弹出后位置固定，避免追着鼠标跑。按住中键拖动仍调用Blender原生旋转，Shift+中键保持平移。
一级：移动、复制、删除、创建关联、解除关联；二级入口：交接处理、截面/规格、端点/画线。中心显示去重选择数，不改变多选；不适用的命令置灰。
再次中键、Esc、右键，或左键点击盘外关闭。盘外关闭点击不穿透改变模型选择。左键点击有效命令后，先关闭操作盘，再执行同一套工程命令，保留确认和撤销。
删除仍有确认。二级入口使用Blender原生菜单，遵循原生菜单交互。顶部长度和截面小窗选槽保留，侧栏原入口也保留。
G/画线过程中不弹操作盘，仍可用中键导航。截面小窗内中键不启动模型操作。非ALU DIY工作区不接管中键；视窗可见区域过小时提示收起N侧栏/放大，不留不可见按钮。

## 三项快速验收
1. 指定并关联某主杆槽轨，工程删除主杆；选原附着端G→X→100，立即成功。删除一次撤销恢复主杆和原关系。
2. 同时选主杆与附着横梁，Shift+D→Y→300→Enter；只移动副本，内部关联保留，原框架不动。一次撤销恢复。再只复制横梁，确认副本独立。
3. 中键轻点打开操作盘，中键拖动只旋转。盘外左右点击不丢失多选；复制取消没有副本，删除取消不修改工程，解除关联可一次撤销。
