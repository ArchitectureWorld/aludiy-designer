# v0.1.19-alpha — 混合吸附 / 多选槽轨 / 批量关联

## 更新与范围
先保存工程副本。原仓库 Refresh Remote → AluDIY Designer → Update，确认0.1.19-alpha。无需卸载或重配仓库。
本版不升级工程数据schema，不改变独立复制、中键操作盘及原L/T加工规则。用户对0.1.18的复制属于初测通过，不扩展为所有功能已验收。

## 1. 普通杆件与槽轨默认共同吸附
指定槽轨不再关闭普通端点、中点、垂足、杆身和地面候选。G与画线共用同一条候选管线；按距离与语义优先级排序，Tab可切换重叠候选，提示给出具体主杆/槽位。
截面小窗的“吸附：普通 + 槽轨 · 切换”可以明确开启“仅所选槽轨”，再点击可返回混合模式。没有已启用槽轨时仍使用普通吸附。
数值输入、X/Y/Z及平面锁优先，Ctrl临时关闭全部吸附。吸附只定位，不自动创建关联。

## 2. 在截面小窗多选槽轨
单击槽口或编号只选这一条；Shift+单击追加/取消这一条。2040同一面的两条平行槽可以分别选择。
选另一根型材后，再在它的截面小窗Shift+单击，可加入跨杆件的同一集合。不同主杆的同名槽也有独立身份。
“已选N条”是待操作集合；“定位N条”是已经点击“用于吸附”启用的集合。点击“用于吸附”一次应用整组；查看或更改槽位选择不悄悄替换已启用目标。
已选槽口为黄色；已用于定位的槽口另有外圈，模型区启用轨道为黄色、仅选中未启用的轨道为蓝色。小窗保留清晰计数，不在模型上叠加常驻尺寸线。

| 小窗命令 | 行为 |
|---|---|
| 用于吸附 | 将已选集合整体设为定位目标；不创建关系 |
| 停止定位 | 停用定位集合，保留槽轨选择与工程关系 |
| 移除当前槽 | 从选择和定位集合移除当前主杆/槽位，保留其工程关系 |
| 清空槽轨选择 | 清空选择及定位集合，保留所有工程关系 |
| 创建关联 | 将所选杆端/杆件与已选槽轨中已经摆准的唯一对应位置匹配 |
| 解除所选端点 | 原通用选择范围解除，不等同于清除定位目标 |
| 解除所选槽关联 | 先列出槽轨和实际关系数量，确认后解除这组精确主杆/槽位的关系 |

## 3. 批量关联与解除
先摆好多个杆端，再选中这些杆件/端点并点击创建关联。仅建立已经位于已选槽轨上的唯一匹配；未命中端点不被移动或强制连接。一个端点命中多条槽轨时整次拒绝，请缩小槽轨选择集合后重试。
批量解除只删选定主杆/槽位的ON_SLOT关系，不把主杆集合与槽位名称组合成错误的笛卡尔积；其他槽、重合节点和杆身约束保留，所有端点位置不变。
确认期间工程/选择变化则拒绝旧命令。创建、解除均支持一次Ctrl+Z和重做；真正解除后可以立即G移动，若端点还有其他约束会继续按其规则限制。
删除一个主杆只清理属于它的临时选择和定位目标，其他目标保留；新建/导入工程清空旧工程的临时目标，防止同名ID误指向新对象。保存重开保留当前工程的选择与定位状态。

## 三项快速验收
1. 选两个主杆上的槽轨并用于吸附，再G移动横梁端：既能命中槽轨，也能命中第三根普通杆件的端点/中点；Tab可区分邻近候选。
2. 在2040同一面的两槽间Shift点选，再换另一根型材追加一槽：计数为3；停止定位不解除现有关系，清空选择不删除几何。
3. 将两根横梁分别摆到不同主杆的所选槽轨，选横梁创建关联；解除所选槽关联并确认后，原端点立即可G移动，未选槽的关系仍存在。撤销、重做和保存重开结果一致。

## 边界
小窗在G/画线过程中只读，点击不会透到背后模型；视图太小会隐藏小窗而不保留不可见命中区。可以平移视图或收起N栏让模型目标处于可操作区域。
槽轨仍是测试目录定义的槽口中心线，并非供应商制造级配合面。没有加入槽轨滑移、阵列/镜像、连接件安装或结构校核。
0.4工程仍不要使用0.1.15或更旧插件覆盖保存。Linux真实Blender验证不等于全部Windows/DPI/第三方插件组合通过；需本机体验验收。
