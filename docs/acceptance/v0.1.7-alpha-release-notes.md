# v0.1.7-alpha — G 与工程端点

本轮优先解决实际建模移动体验，不代表原路线图的“完整工程吸附”已经实现。

- 新增仅对工程对象生效的 G 模态移动；普通 Blender 对象继续使用原生命令。
- 两侧视窗显示屏幕尺寸稳定的绿色起端、红色终端控点。先选杆件再选端点，保留所属杆件身份。
- 默认保持连接，显式“断开此杆端”仅拆分该杆端；公共点及其他杆件保持不变。
- 多选去重、世界轴/平面、毫米数值、位置吸附、双窗实时预览、取消、一步撤销及重做。
- 预览只修改可恢复显示缓存；确认才写工程数据。失效/零长度方案不能提交。
- 修复双窗选择同步清除多选、重建后立即选择失败、界面图标不兼容。
- 提供真实 Blender 后台与 X11 窗口键鼠回归脚本；测试不是用 mock 替代真实界面。

版本号按当前 Preview 规则使用 Manifest 0.1.7、界面 0.1.7-alpha；保持 aludiy_designer ID。
