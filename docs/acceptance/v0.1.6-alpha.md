# AluDIY Designer v0.1.6-alpha 体验验收

## 安装／迁移

首次远程版本发布后，将仓库地址添加到 Blender：

```text
https://architectureworld.github.io/aludiy-designer/index.json
```

从本地 ZIP 版迁移时，可能需要最后卸载一次 v0.1.5-alpha，再从远程仓库安装 v0.1.6-alpha。后续版本使用 `Refresh Remote → Update`。

## 验收 1：精确长度

1. 选中一根 1200 mm 型材。
2. 输入 `1500`。
3. 分别测试固定起端、固定末端、固定中心。
4. 核对线图、三维体、相邻杆件和参考尺寸同步更新。

## 验收 2：节点坐标

1. 在线图中选择一个共享节点。
2. 点击“编辑节点坐标”。
3. 输入新的 X / Y / Z。
4. 核对所有连接该节点的型材均跟随，且没有生成重复节点。

## 验收 3：端点与平移

1. 选择型材，在“工程对象信息”中编辑起点、终点。
2. 使用“精确平移”，输入 `ΔX / ΔY / ΔZ`，可测试 `-100`、`20+5`、`0.3m`。
3. 核对共享节点关系与相邻型材传播。

## 验收 4：视口反馈

- 选中型材：左侧显示临时参考尺寸；
- 选中节点：左侧显示节点坐标；
- 缩放、旋转和切换两侧选择时，无叠加层报错。

## 验收 5：保存与撤销

1. 完成上述修改后保存 `.blend` 并导出 `.aludiy.json`。
2. 使用 `Ctrl + Z` 验证工程数据和两侧缓存整体恢复。
3. 重新打开项目，坐标、长度和型材 ID 保持一致。

## 当前边界

- 临时尺寸不能直接在视口中点击编辑；驱动输入位于 N 面板／弹窗。
- 尚未建立持久尺寸约束、节点退让、连接件与制造长度。
- 真实 Blender 5.2 GUI 操作必须在目标机器完成，普通 Python 测试不能替代该验收。
