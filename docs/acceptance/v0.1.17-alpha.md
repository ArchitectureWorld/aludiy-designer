# v0.1.17-alpha — 空白面板修复

## 更新
先保存工程副本。偏好设置 → 获取扩展 → Refresh Remote → AluDIY Designer → Update。
更新后确认 0.1.17-alpha；如 Blender 提示重启，按提示重启。无需卸载、删除配置或清空工程。

## 根因与修正
已在干净的 Blender 5.2.2 中复现与用户截图一致的结果：显示版本号后只剩一个空框。
顶部“当前选择/长度”在空工程首次绘制时调用 get_project，旧实现会把空工程写回场景。
Blender 的 Panel.draw 不允许这种写入，抛出 Writing to ID classes in this context is not allowed，后续布局中止。
修复后读取空工程只返回内存对象，不初始化或覆盖 project_json；第一次明确建模/导入时才保存数据。
若已有工程内容无法读取，面板显示具体错误，并保留设置视窗、另存副本和导入入口；不会静默清空工程。

## 验收
1. 普通新场景（只有默认 Cube、未创建 AluDIY 工程）打开 N → AluDIY，应直接显示当前选择、设置双视窗及下方各功能区。
2. 在新建的第二个场景、保存重开的空场景中同样可见；首次插入样例仍可正常生成。
3. 已有工程的长度、截面槽位、解除关联及 L/T 退让行为保留。本版不改变数据格式、不删除关系。

本次针对已复现的绘制异常修复。用户尚未提供本机控制台堆栈；若更新后仍报错，应按面板显示的具体异常继续定位，而不是推定工程已损坏。
Linux 实测与自动回归不代表所有 Windows、显示缩放和第三方插件组合均已验收。
