# AluDIY v0.1.7-alpha · G 与端点体验验收

本版通过现有 Preview 仓库直接更新，扩展 ID 仍为 aludiy_designer。
保存测试工程 → 获取扩展 → Refresh Remote → AluDIY Designer → Update。
更新后确认 N → AluDIY 显示 0.1.7-alpha；不要同时启用旧本地 ZIP 副本。
若更新提示重启则按提示重启，不要求重复卸载安装。

## 1. 选择和移动
在 ALU DIY 双视窗、对象模式下进行；不要进入网格编辑模式。
- 整杆：选中线或实体 → G → 鼠标拖动 → 左键或 Enter 确认。
- 端点：先选一根型材 → 点击绿色起端或红色终端圆点 → G。
- 也可使用主面板“移动与端点”中的“起端（绿）/终端（红）”按钮。
- 公共节点可独立选中后 G，默认保持所有相连杆件连接。
- G 后 X/Y/Z 限制世界轴；Shift+X/Y/Z 排除该轴，限制在平面。
- 输入默认单位 mm，例如 G Z 100 或 100mm；1.2m、120cm 等沿用长度解析器。
- 鼠标自由移动使用当前观察平面，不等于自动推断三维设计意图。
- 从 N 面板“G·鼠标移动”启动时，移入视窗后先左键确定鼠标移动基点。

## 2. 保持连接与断开
先选型材的具体端点，主面板出现“保持连接 / 断开此杆端”。
保持连接为默认：共用这个节点的所有杆件端点跟随；没有选中的远端不动。
断开此杆端：只分离当前杆件这一端，其他杆件和原节点不动。
每次完成或取消后恢复 KEEP 默认；不自动焊接位置重合的节点。
直接选择一个公共节点时无法确定分离哪根杆件，因此不提供模糊分离操作。

## 3. 五个必测动作
| 场景 | 操作 | 预期 |
|---|---|---|
| 端点保持连接 | 立柱顶部与两横梁共点，点顶部 → G Z 100 | 顶点升高100，横梁近端跟随，远端不动；左右同时预览 |
| 端点分离 | 撤销，选同一立柱端点 → 断开此杆端 → G Z 100 | 只延长立柱，两横梁及原交点不动 |
| 取消与撤销 | 拖动中 Esc/右键；确认后 Ctrl+Z；Ctrl+Shift+Z 重做 | 位置和共享/分离关系一起恢复，不留孤立点 |
| 整组移动 | 多选两根相连型材 → G Z 100 | 共同节点仅位移一次，不会叠加成200；只选一根则仅其两端一起动 |
| 普通对象 | 仅选普通 Cube → G | 保持 Blender 原生移动，AluDIY工程数据不变 |

## 4. 已执行验证与限制
Linux Blender 5.2.2 实际后台及 Xvfb/XTest 窗口事件测试已经执行；Windows 鼠标、DPI、其他插件组合仍需用户体验验收。
拖动预览不修改持久工程 JSON；确认后一次性提交。BOX 与简化槽型显示均参与预览。
本轮没有完整工程吸附、约束求解、原生 R/S、网格编辑模式同步或制造级截面。
移动靠近现有节点仅提供位置吸附，不自动建立新连接。
不改变 X/Delete/Shift+Delete；工程删除仍为 Ctrl+Shift+Delete。
混合选择普通和工程对象时会提示分开操作，不静默只移动其中一部分。
导出/导入简单测试通过沿用用户反馈，不视为全部异常工况验证完成。
