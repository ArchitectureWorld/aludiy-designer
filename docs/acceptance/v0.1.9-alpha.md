# v0.1.9-alpha · G 默认吸附与端点重新连接

**状态：Preview 测试版；本版 Windows 用户体验待验收。**

## 当前交付范围

延续 0.1.8 样例追加与工程数据保护；本轮修改 G 移动，不把杆件中部定位假称为完成了 T 型节点或槽口连接。

- G 默认寻找工程节点/端点；绿色目标提示“确认后连接”。确认时复用目标 Node ID，而不是只移动显示对象。
- 先 G，再按住 Ctrl：关闭本次吸附与新连接；松开立即恢复。原有 KEEP / DETACH 关系独立，不因为自由移动自动拆开框架。
- 选择明确杆端后，“连接到目标…”启动点选目标；已经重合但独立的节点也能连接，无须先移开。
- 多个近邻或重合节点：移动过程中 Tab / Shift+Tab 切换；不进入编辑模式。
- 整根/成组移动：以启动 G 时鼠标最近的选中端点为吸附基点，HUD 显示源节点；共享节点只移动一次。只连接明确命中的一个基点，不批量自动焊接其他重合端点。
- 可设置“地面标高”（默认毫米，支持 0.1m 等单位），蓝色提示“仅定位”。不合并节点、不生成固定或承载约束。它定位的是设计端点，不是复杂截面外表面或切割端面的落地校验。
- 精确输入优先：不会把 -199mm 偷改为 -200mm；恰好到达节点时可连接。按住 Ctrl 确认可保持独立。
- 轴/平面锁定仍有效；导致零长度的连接不允许提交。预览不写 JSON，Esc/右键取消，Ctrl+Z 一步撤销。

## 更新与验收

保存工程，现有远程仓库 Refresh Remote → AluDIY Designer → Update，确认面板 0.1.9-alpha。不把先用 ZIP 测试作为远程发布前置。

| 测试 | 操作 | 预期 |
|---|---|---|
| 接回原节点 | 选分离端点→G→移到原节点→确认 | 绿色目标提示，确认后再次移动会带动关联杆件 |
| 接到新节点 | 选择“断开此杆端”→G→命中另一个端点→确认 | 只将选定杆端改接，原节点和其他杆件保持原关系 |
| 临时自由 | G 拖到目标附近→按住 Ctrl→确认 | 不吸附，不新建关联；松开 Ctrl 则重新吸附 |
| 原位重新连接 | 已重合的独立端点→“连接到目标…”→点目标 | 零位移也能建立共享节点关系 |
| 落地 | 选悬空立柱底端→G→Z→接近地面标高 | 蓝色提示；准确定位，不增加型材连接或约束 |
| 多候选 | G 靠近重合目标→Tab | 可见目标 ID 改变，选中哪个才连接哪个 |
| 数据闭环 | 预览取消、确认后撤销/重做、保存重开 | 原位置和连接关系恢复/保留一致 |

## 边界

只在 AluDIY 工程移动上下文接入；普通 Blender 对象的原生 G、Ctrl+G 和删除快捷键不改写。
这一版不包含中点/侧面/槽轨的持久附着、任意参考网格表面吸附、完整尺寸约束、L/T 自动退让、连接件或承载验证。
俯视中高度不可判定时，不凭屏幕重合猜测地面；换成斜视/立面，或输入明确位移。
“设计关联已建立”不等于“物理连接件可装配/结构安全已通过”。Windows/DPI/其他插件共存仍需用户体验验收。
