# AluDIY Designer v0.1.5-alpha 体验式验收

## 环境

- Blender 5.2.x LTS
- 安装包：`aludiy_designer-0.1.5.zip`
- 安装方式：Preferences → Extensions → Install from Disk

安装后在 3D Viewport 按 `N`，确认页签顶部显示 `AluDIY 0.1.5-alpha`。

## 1. 单根工程删除

1. 新建空白项目，或生成矩形样例框架。
2. 在线图视窗选择一根工程线。
3. 按 `Ctrl + Shift + Delete`。
4. 在确认框中确认删除。

预期：

- 左侧工程线和右侧对应型材实体同时消失；
- 中央工程数据中的 Member 被删除；
- 只属于该型材的孤立节点被清理；
- 与其他型材共享的节点继续保留；
- 状态栏显示删除型材数和清理节点数。

## 2. 从实体视窗删除

1. 在右侧三维视窗选择型材实体。
2. 按 `Ctrl + Shift + Delete` 并确认。

预期与从左侧工程线删除完全一致；同一 Member 不存在两套删除逻辑。

## 3. 多选与重复缓存

1. 同时选择多根型材。
2. 如果同一 Member 的线和体均被选中，也保持选择。
3. 执行工程删除。

预期：同一 Member 只计数、删除一次；其他选中 Member 同步删除。

## 4. 普通 Blender 对象不受影响

1. 新建一个普通 Cube。
2. 同时选择 Cube 和一根 AluDIY 型材。
3. 执行 `Ctrl + Shift + Delete`。

预期：只删除 AluDIY 工程型材，普通 Cube 保留。

再分别测试 Blender 原生 `X`、`Delete` 和 `Shift + Delete`：其按键映射没有被 AluDIY 改写。

## 5. 撤销

完成工程删除后按 `Ctrl + Z`。

预期：工程 Member、工程线、三维实体及被清理的孤立节点一起恢复。

## 6. 面板入口

在 N 面板“选中型材”区域点击“删除工程型材”。

预期：行为与 `Ctrl + Shift + Delete` 完全一致，并出现删除确认框。

## 当前边界

- 原生 `X / Delete / Shift + Delete` 仍属于 Blender 缓存对象操作，不代表工程删除；误删显示缓存后可使用“重建场景”恢复。
- Outliner 中直接删除缓存对象尚未转化为工程删除。
- 当前工程数据只包含 Node 与 Member；Joint、Panel 等后续关系尚未进入级联删除。
