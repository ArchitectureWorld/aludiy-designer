# v0.1.8-alpha：样例数据保护

## 已确认的用户反馈

2026-10-15：用户报告生成矩形样例会删除此前手绘型材；G 移动简单测试暂未发现问题。移动记为“简单场景体验通过”，并非全量验收。此前 JSON 导出导入简单测试通过。

## 本版变化

- “生成矩形样例框架”改为“插入矩形样例”。
- 向当前工程追加四根杆件与四个新节点，保留现有工程 ID、目录修订、已有节点坐标、杆件参数及连接关系。
- 样例起点是 Blender 3D 游标，位于世界 XY 平面。游标方向不作为截面或平面旋转依据。
- 新样例不与旧节点自动焊接。同一位置重复插入可能形成重叠但独立的样例。
- 复用工程事务：显示重建成功后提交，失败恢复原工程和缓存。
- 新建空白项目有已有内容时，先弹“清空当前工程并新建”确认；取消不改变数据。普通 Blender 对象不在工程清空范围。
- 插入与确认清空支持 Blender Undo；不是原生 X / Delete 的拦截。

## 体验验收

先保存有效工程副本。在现有 Preview 仓库刷新并更新到 0.1.8，不要求先 ZIP 测试再发布。

| 操作 | 通过标准 |
|---|---|
| 手绘若干杆件后插入矩形样例 | 原杆件仍在，总杆数增加 4 |
| 改变 3D 游标位置后插入 | 新矩形从游标位置生成，旧杆件位置不变 |
| 连续插入两次 | 总杆数增加 8，旧数据与新样例 ID 均不互相覆盖 |
| Ctrl + Z / 重做 | 只撤销最近一次插入，重做可恢复 |
| 新建空白项目后取消 | 原设计完整保留 |
| 确认清空后撤销 | 工程恢复，普通 Cube 始终不被删除 |
| 插入后 G 移动一根旧杆及一个新杆 | 原有移动逻辑正常 |
| 保存、重新启动、打开 | 旧设计与插入内容均保留 |

## 验证边界

Python 回归测试包含旧版问题复现、重复插入、原 ID 与参数保留、非法输入和缓存失败回滚。真实 Blender 5.2.2 Linux/X11 检查由 Sample Safety Verification 工作流执行，包括原有移动回归。最终是否通过以对应工作流和 evidence/report.json 为准；Windows 本机体验未在本说明中预先宣布通过。

旧版覆盖已经发生时，优先使用未失效的撤销历史或工程备份；更新本身无法还原从未保存且撤销记录已丢失的设计。
