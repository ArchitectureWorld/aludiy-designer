# v0.1.11-alpha · 画线与移动统一吸附

状态：Preview 测试版。本版建立于用户基本体验通过的 0.1.10；不把简单体验扩大为全场景验收。

## 更新
保存工程副本，在原远程仓库 Refresh Remote → AluDIY Designer → Update，面板显示 0.1.11-alpha。无需先用 ZIP 测试，也无需卸载重装。

## 本版功能
- 在线图视窗启动“连续绘制型材线”。首点可以吸附到已有杆件的端点、中点和杆身设计轴线，包括任意标高。不要把自由定位面 Z=0 当作只能在地上画。
- 确定起点后，增加起点到目标杆身的数学垂足，适合画垂直于目标杆的连接杆。垂足仅限真实线段内，不把延长线上的投影叫作杆身连接。
- 画线和 G 共用候选与投影/射线单位转换。目标显示类型、Member/Node ID、距杆件起端的距离与总长；全部只定位，不自动建立关联。
- 语义目标在屏幕阈值内优先级为端点、中点、垂足、轴线；Tab/Shift+Tab 可切换近邻候选，包含重合但 ID 不同的节点。
- 进入画线或 G 后按住 Ctrl 暂停吸附，松开立即恢复，不会因此解除已有工程关联。
- X/Y/Z 锁定轴；Shift+X/Y/Z 锁定排除该轴的平面。显式锁定限制全部候选。未显式锁定时，构造平面是鼠标自由定位的后备平面，吸附仍可选到空间中的目标。
- 输入长度、单位表达式、@长度<角度优先。端点坐标不经过 Blender 低精度向量回写；实际没有到达吸附目标时不会仍显示吸附标记。
- 两个 AluDIY 三维视窗均显示相同目标与画线预览。操作仍从左侧线图启动；另一视窗/侧栏点击不会误生成新线。

## 操作示例
在左侧 N → AluDIY → 精确空间线驱动 → 连续绘制型材线（也可把鼠标放在线图中，F3 搜索该命令）。

1. 鼠标靠近横梁中点，看到“中点 M-… · 仅定位”后点击。
2. 按 Z，向上移动鼠标，输入 300，Enter。立柱从横梁真实标高向上 300 mm，不需要先算 XYZ。
3. 右键结束画线。新线端点仍然独立；多选横梁与新立柱，点击“创建关联”，才建立杆身附着。

## 重点验收
| 测试 | 预期 |
|---|---|
| 高位横梁中点起画→Z→300→Enter | 在正确标高生成 300 mm 立柱，旧杆件不被删除 |
| 杆身任意位置起画 | 不限于端点；提示目标杆件与沿杆距离 |
| 起点到另一杆身垂足 | 出现“垂足”标记，落点在真实杆身线上 |
| Ctrl 按住/松开 | 不额外移动鼠标也能切换吸附；无隐式绑定 |
| Tab/Shift+Tab | 候选目标变化，不进入编辑模式 |
| 输入349，目标距起点350 | 保留349，不偷偷改成350；未到达目标不画吸附标记 |
| 显式Z或Shift+Z锁定 | 不被轴外/平面外候选拉走 |
| 画线后手动创建关联，再移动主杆 | 附着端按0.1.10既有规则跟随，主杆不拆断 |
| 结束画线后撤销/重做、保存重开 | 数据、线、体、已创建关联一致 |

## 取消与数据安全
每次左键/Enter 确认保留一段；Esc/右键结束连续画线，取消尚未确认的一段，不删除已经画好的段。结束后一次 Ctrl+Z 撤销本轮连续画线（不是逐段撤销）。
不改变0.2.0关联数据结构。旧工程共享节点和手动关系保留；新画端点仍默认独立。含显式关联的新工程仍不要用0.1.9或更旧版本覆盖保存。

## 边界
这是设计轴线/标高定位，不是型材外表面或真实槽位吸附。任意实体表面、槽轨兼容、复杂交点/延长线、自动退让、连接件与结构安全检查仍未包含。
画线使用所选构造平面作为无吸附时的后备平面；G 保留屏幕平面自由拖动与可选地面标高定位。它们共用候选，但无吸附时的自由定位平面并不强行统一。
Windows、显示缩放、其他插件共存和大型框架性能需用户本机验收。没有声称所有检查均为全程鼠标人工操作。
