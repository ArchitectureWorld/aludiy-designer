# v0.1.16-alpha — 截面槽轨控制台 / 明确解关联 / L·T 直角退让

## 更新
保存工程副本，在原仓库 Refresh Remote → AluDIY Designer → Update，确认面板 0.1.16-alpha。无需手动卸载，ZIP 只是备用。用户对 0.1.15 的吸附与顶部长度反馈通过；不扩大为全部功能/环境已验收。

## 1. 槽轨相关操作统一到截面小窗
直接点击槽口或编号，小窗内完成“用于吸附”“停止定位”“创建关联”“解除所选”“解除此槽关联”。侧栏不再重复槽轨操作区；通用多选关联入口仍保留，方便没有截面小窗的节点操作。
小窗显示当前查看槽、定位目标、此槽关联数、所选关联数。换选型材不改变已固定的定位目标；查看槽与目标槽都写明所属对象。小窗沿用原来的大小，不增加遮挡区域；极小视窗仍隐藏，不保留不可见点击区。

**停止定位不是解除关联。**它只恢复普通吸附；现有工程关联保留，并明确提示剩余数量。槽轨线消失不能代表约束已解除。
**解除所选**：选中具体附着杆端，再点击小窗按钮，解除这个选择范围的关联，保留位置和端点选择。
**解除此槽关联**：先选主杆，再点需要处理的那个槽，按钮显示关系数量；确认后删除此主杆/此槽的全部 ON_SLOT 关系，其他槽及其他约束保留。取消确认不改动工程。只移除这一槽的约束；节点若还存在别的约束，需要另行解除。
小窗数据操作支持一次 Ctrl+Z / 重做。画线和 G 进行中小窗只读，不把点击透传到模型；其他 Blender 对象混入选择时拒绝关联操作，不丢失选择。

## 2. L / T 直角交接与实体端面退让
入口：N → AluDIY → **交接与端面退让 · 首版**。

1. 用已有画线/G吸附摆好两根相接型材，轴线正交，支杆垂直主杆一个截面外侧面。
2. 先选支杆，Shift 最后选主杆。只选这两根；面板明确显示“主杆（当前） / 支杆”。
3. 填写非负“端面间隙 mm”，点击 **设置 / 更新 L·T 直角交接**。
4. 主杆中部的交会识别为 T，主杆保持完整，支杆实体退至主杆外廓面并留出间隙。主杆设计端点的交会识别为 L，支杆退让，主杆实体端部补齐支杆厚度范围。
5. 设计线、节点和位置关联不动；BOX / 型材细节两种实体显示都按规则更新。顶部保留“设计线长度”，另列“实体参考长度”和起/终端退让；正值缩短，负值补长。
6. 仍选相同主支杆修改间隙，会更新原规则，不叠加扣减。**清除所选交接**恢复未退让实体，不解除空间关联；支持一次撤销。

当前内置2040测试截面是 U40×V20，不按型号名称猜方向。以主杆竖直且U面朝向横梁为例：500mm设计横梁，主杆面距轴20mm，零间隙实体参考长度480mm；2mm间隙则478mm。顶部L形使用2020支杆时，1000mm主杆可补长为1010mm。更换朝向后数值跟随实际局部坐标重新计算。

## 3. 自由调整不被加工规则卡住
交接是实体加工规则，**不是新位置约束**。解除位置关联后 G 可以移动；若移动造成斜接、脱离接合面等不支持状态，保留该规则但标记“交接待处理”，暂停整份工程的退让显示，恢复未退让实体，并禁止输出加工参考清单。调整回合法位置或清除交接后恢复；不能在规则失效时暗中给出看似正确的切割长度。

“导出长度 / 退让参考清单”包含设计长度、起终端退让和实体参考长度。这是测试目录的几何参考，不是供应商加工单；未做连接件安装、碰撞、刀缝余量或承载校核。无效规则不覆盖已有CSV文件。

## 三组体验验收
| 场景 | 操作与预期 |
|---|---|
| 报告的解除问题 | 创建槽轨关联→停止定位，明确显示仍有关系；选主杆对应槽→解除此槽关联→确认→选原附着端 G X 100，立刻可移动；其他槽的关系保留。撤销/重做可恢复/解除。 |
| T形端面退让 | 两根设计轴线在主杆中部正交，最后选主杆，设置0/2mm间隙；设计线不动，支杆实体端面按截面退让，顶部两种长度和CSV一致。 |
| L形与保存重开 | 在主杆端点设置L，主杆补长、支杆退让；改间隙、撤销、保存重开结果一致。自由移动使规则失效时提示待处理，不冒充可出料。 |

## 数据兼容与范围
首次创建交接规则升级为 **schema 0.4.0**。没有交接规则的旧工程不自动升级；继续读取0.1/0.2/0.3工程及槽轨关联。0.4工程请另存，**不要用0.1.15或更旧插件覆盖保存**。旧槽轨关系的换型保护仍保留。
首版只有矩形外廓、正交且垂直主杆侧面的平端面对接，不含45°拼角、斜切、沿槽滑移、连接件选配、供应商制造级截面或强度结论。T形太靠近端部而不能覆盖会拒绝，不自行猜成L。实体退让不改变有限设计槽轨的起终域。
Windows、显示缩放、第三方插件、多系统窗口及大型工程性能仍需本机体验确认。依然从左侧线视窗启动画线，右侧同步预览。
