# v0.1.12-alpha — 型材换型、截面朝向与槽位检查

基线 0.1.11：用户反馈数值移动效果良好，吸附没有问题、锁定暂未发现问题。仅记为基本体验通过，不扩大为全场景验证。用户不优先要求右侧实体视窗启动画线，本版继续从左侧线图启动。

## 更新
保存工程副本，原远程仓库 Refresh Remote → AluDIY Designer → Update。面板为 0.1.12-alpha。ZIP 仅为备用，不要求先 ZIP 验收后发布。

## 新入口
N → AluDIY → **型材规格与截面朝向**，位于“移动与端点”上方。
- 单选或 Shift 多选杆件，选择目标规格，点击“替换所选型材规格”。目标规格独立于下方新画杆件的默认规格。
- “截面 −90° / +90°”对每根所选杆件的现有朝向分别加减90°。
- “角度 ° → 设置”把全部所选杆件设为同一个绝对截面角度。支持 45+45、90deg、90°；不接受 mm、m 长度单位。
- 旋转绕各根设计轴线，不是整个框架旋转。节点坐标、设计线、长度和既有轴线关联保持不变。
- 选中型材会在双窗显示活动型材的截面示意。多选只展示当前活动项的截面，但命令作用于全部选中杆件；不是只改变最后一根。
- 点击槽位按钮，二维示意与三维沿杆槽轨同步高亮。不同型号的槽数/封闭面来自现有测试目录；不能把没有槽的面当成有槽。
- 换型后清除上次槽位检查，不按同名 ID 猜测接口兼容。旋转不改变稳定槽 ID，只改变它在空间的位置。

## 四项快速验收
1. 多选两根杆，目标规格选 **20×40 六槽（测试）**，替换。两根实体都变化，线和节点不动；多选高亮数量不变。
2. 点击“截面 +90°”，观察20×40长短边转向。一次 Ctrl+Z 恢复两根截面的原角度；再重做。
3. 只选一根，勾选查看截面与槽位，依次点同一面的两个槽按钮；查看稳定接口 ID 与高亮轨道。切换三槽测试规格后，只有三个有效槽。
4. 切换 BOX/型材细节，多选集合保持；保存后重新启动，规格、角度和关联一致。原有 G、手动关联与画线继续正常。

## 数据与边界
沿用现有 Member.profile_type_id/roll_deg，不增加 schema；支持0.1.11工程。含0.2.0显式关联的工程仍不要交给0.1.9或更旧版本覆盖保存。
当前五种截面是语义测试目录，槽形示意不是供应商精确 DXF。槽位检查不会开启槽轨吸附、自动创建附着或验证连接件兼容。
已有杆身关系仍基于设计轴线，换型或旋转不会改变其定义；不表示真实侧面接口已经匹配。槽轨附着、精确截面、退让、连接件、承载模拟待后续版本。
roll=0沿用旧版局部坐标基准；正负角度遵循该基准，并非任意相机视角下的“屏幕顺时针”。示意图注明从终端看向起端。
Windows、显示缩放、其他插件共存及大型工程性能仍需用户本机验收。
