# v0.1.14-alpha — 槽轨定位与手动附着

## 更新
保存工程副本。原远程仓库 Refresh Remote → AluDIY Designer → Update。面板显示 0.1.14-alpha，无需先卸载或用ZIP验收。0.1.13的工作区/透视同步修复保留；本轮不把用户此前的简单反馈扩大为全场景验收。

## 主要操作
1. 选主杆，在“型材规格与截面朝向”中点击需要的槽位按钮，再点 **设为槽轨定位目标**。两个视窗出现黄色目标轨道与 `M-xxx / FACE_…S…`，选其他杆件时该目标不会丢失。
2. 选待移动的杆端，按 **G** 靠近目标轨道。命中后提示沿槽位置/总长及“仅定位”。左键/Enter确认，只调整位置，不创建关系。也能在左侧启动“连续绘制型材线”，从该槽的起端、终端、中点、任意沿槽位置或垂足起画。
3. 摆准之后多选主杆和附着杆/节点，点击 **创建关联**，或使用“创建槽轨关联”。已经指定目标时，关联命令只针对这个槽轨；也可只选具体杆端后创建。没有指定目标时，多选相接杆件会识别唯一端点/轴线/槽轨关系；有多个匹配会提示缩小选择，不能偷偷猜。
4. 移动主杆，附着端跟随；主杆截面旋转，端点跟随同一稳定槽ID的空间轨道。主杆改长后按相对站位跟随，例如中点仍为中点。另一端不会自动整体平移，杆件可能改变方向/长度。
5. **清除目标**恢复普通端点/杆身吸附，不解除已有关系。**解除所选关联**才解除工程约束，保持当前位置。已附着的从属端单独移动会提示先解除；本版不增加沿槽滑移约束/拖动模式。

普通G和画线默认吸附。进入操作后按住Ctrl临时关闭，松开恢复。轴/平面锁定、数值优先和Tab候选切换不变。指定槽轨时仅寻找该轨道的候选，避免细密平行槽与轴线争抢；清除目标后恢复普通吸附。

## 三项验收
| 场景 | 预期 |
|---|---|
| 2040同一面的两条槽分别指定为目标 | 高亮位置和Interface ID不同；G落到指定轨道，不是主杆中心线 |
| 吸附确认，再手动创建关联，再移动/旋转主杆 | 创建前独立，创建后附着端跟随；主杆仍为一根；解除后位置不变 |
| 关联后Ctrl+Z/重做、保存重开 | 一次撤销恢复对应操作的几何/关系；重开规格、角度、槽ID与站位一致 |

带槽轨附着的主杆 **换型会被阻止**。应先明确解除对应关联，换型后重新指定接口；即使新旧型材槽ID同名，也不自动认为兼容。仅改变截面角度则正常联动。

## 数据边界
- 首次创建槽轨关联使用 **schema 0.3.0**；0.1.13及更旧插件不支持这种新关系，请勿降级覆盖新工程。
- 0.1.0/0.2.0工程和旧共享节点可继续读取；没有槽轨关系时不自动升级。新关联记录 Member+Interface+相对站位，并保存带规格/目录版本身份的不可变接口UV引用快照，便于离线验算。载入时检查目录一致性，失配拒绝静默改配。
- 本版定位 **工程端点到测试目录中的槽口中心轨道**；不是型材真实接触面、连接件安装偏距、切割退让或物理咬合。可能出现尚未处理的实体相交，不表示制造或承载安全。
- 槽位不能由2020/2040尺寸猜测，只有目录真实声明的语义接口有效。供应商准确DXF、槽轨兼容、自动退让与连接件继续留在后续版本。
- Windows、显示缩放、第三方插件和大模型性能待用户本机验收。右侧只同步预览，仍从左侧启动画线。
