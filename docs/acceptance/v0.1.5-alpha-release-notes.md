# AluDIY Designer v0.1.5-alpha 发布说明

## 本版重点：工程删除闭环

- 新增 `Ctrl + Shift + Delete` 专用工程删除快捷键。
- 保留 Blender 原生 `X / Delete / Shift + Delete` 行为，不覆盖常规软件操作。
- 从工程线或三维实体选择同一 Member，均删除中央工程对象。
- 同步重建左右视窗缓存，避免只删线或只删体。
- 多选去重；普通 Blender 对象不受影响。
- 删除后只清理本次型材端点中不再被任何剩余型材引用的孤立节点。
- Operator 支持 Blender Undo，`Ctrl + Z` 可恢复工程数据和显示缓存。
- N 面板新增“删除工程型材”按钮。
- 快捷键作为可降级服务注册；即使键位注册失败，核心面板和按钮仍可使用。
