# v0.1.10-alpha：吸附仅定位、多选可见、手动关联

## 更新与操作

现有 Preview 仓库 Refresh Remote → AluDIY Designer → Update。版本 0.1.10-alpha。先保存工程副本；不用卸载。

- Shift 多选杆件或节点，所有选中项持续描边，最后活动项更亮；左右视窗显示去重后的杆件/节点数量。实线是主动选择，虚线是关联影响，菱形表示已有关系。
- 普通 G 默认吸附端点、杆身设计轴线/中点与地面，只改变位置，不自动合并节点。按住 Ctrl 临时关闭吸附。G 仍保留已明确创建的关系。
- 连续画线与插入样例现在为每根杆件分配独立端点；位置重合不表示关联。旧工程已经共用的节点不因更新被拆散。
- 多选相接杆件或重合节点 → 主面板“创建关联”。端点关系保留各自 Node ID；杆身关系记录主杆和相对位置，不把主杆切成两根。无需手工算坐标。
- 多选目标不明确（多个重叠主杆等）时拒绝本次创建，要求缩小选择范围；不猜测主杆、不移动几何凑连接。
- “解除关联”保留现有位置，并解除所选对象的相关关系。部分解除后未选中节点之间的关系保留。旧共享节点仅在明确解除时拆开。
- 杆身附着是单向主杆 → 附着端，保存归一化位置 t。例如 t=0.5 始终在主杆中点；主杆加长后按比例跟随。附着端的另一端不会自动跟随，杆件可能变斜。与主杆固定附着冲突的移动会明确拒绝，应解除关系或一起选主杆，不静默拉动主杆。
- 吸附的精确坐标与提交载荷用 Python 双精度数值保留，不通过 Blender 的低精度 Vector/FloatVectorProperty 往返后再验证连接。

## 本轮验收

| 操作 | 预期 |
|---|---|
| Shift 选三根杆件 | 三根都高亮，计数3；右侧线/体别名不重复计数 |
| G 将一个独立端点摆到其他端点，再移开 | 不自动创建关联，其他杆件不动 |
| G 将端点摆到立柱中段 | 显示中点或杆身轴线，仅定位 |
| 多选立柱和已靠上的横梁，创建关联，再移动立柱 | 横梁附着端随动，立柱仍是一根；影响杆件虚线可见 |
| 多选重合节点创建关联，移动其中之一 | 其他关联节点跟随；普通同位置未关联节点不跟随 |
| 解除横梁关联后移动 | 横梁独立，其他关系不被无关清除 |
| Ctrl 临时自由、Esc 取消、一次 Ctrl+Z / 重做 | 位置、关联、选中状态一致；预览不提交 |
| 先手绘，再插入样例并撤销 | 原内容保留，样例追加4根/8个独立节点 |
| 保存并重新启动打开 | 关联关系与几何一致保留 |

## 数据兼容与范围

没有新增关联的旧 schema 0.1.0 项目保持原格式/旧共享节点。首次创建显式关联时使用 schema 0.2.0；请另存副本，不要用 0.1.9 或更旧版本打开并覆盖新的关联项目，旧版不理解关联记录。无关联的更新不是自动断开旧工程。

此版的杆身目标是设计轴线，不是供应商 T 槽、侧面间距或制造级接口；不包含自动退让、连接件、物理碰撞、承载校验、任意角度结构约束。关联循环和歧义主杆会被拒绝。本地与 CI 的 Linux Blender 验证不能替代 Windows/DPI/第三方插件共存体验。
