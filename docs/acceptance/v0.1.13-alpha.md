# v0.1.13-alpha — 双视窗进入与透视同步

## 更新
保存工程副本，原仓库 Refresh Remote → AluDIY Designer → Update，确认面板 0.1.13-alpha。无需卸载或重新添加更新地址。

## 已修正
- “设置双视窗工作区”只创建/复用一个 ALU DIY，并自动进入，不再把原 Layout 改名后停留在 Layout.001。
- 重复点击不会新增工作区或继续分屏。等待 Blender 完成原生切换、分屏布局后才配置左右角色；状态先显示正在设置，完成才显示就绪。
- 第一次从原工作区建立时，继承当时三维视图的方向、中心、缩放、投影与焦距；原 Layout 保持原样。
- 重设已有 ALU DIY 时以右侧实体视图为准，立即对齐左窗。线图不再固定为正交视图。
- 完全同步包含透视/正交切换、焦距、裁剪、相机视图框等，单独切换投影无需再手动旋转一次才能触发。
- 切回工作区、插件重新启用或保存重开时自动建立初始同步。停用时清理延迟初始化和同步服务。

## 三步验收
1. 在普通 Layout 点“设置双视窗工作区”：自动进入 ALU DIY，原 Layout 保留；从 Layout 连续重复点击也不再出现新的 .001/.002，ALU DIY 内仅保留原双窗。
2. 右侧为透视时重新设置或切回 ALU DIY：两侧立即均为透视。鼠标分别放在左右视窗，按小键盘5切换投影，两侧一致；旋转、缩放、平移继续同步。主动选择正交时两侧也都为正交。
3. 保存重开后无需手动切换；多选 G、画线、关联、换型与截面旋转仍正常。

## 注意
旧版已生成的 Layout.001 不会自动删除或重命名，以免误删你的自定义布局；本版防止再次产生，并复用现有 ALU DIY。
“方向与中心”模式保留各自缩放，“关闭”模式保持独立。没有升级工程 schema，也不自动清除任何关联。线/体的角色隔离仍保留；从左窗启动画线不变。
Windows、显示缩放、其他插件、多个系统窗口、临时/最大化编辑器的所有组合仍需本机验收，不能以 Linux 自动检查代表全部环境。
