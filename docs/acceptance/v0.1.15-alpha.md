# v0.1.15-alpha — 截面直接选槽 / 顶部长度信息

## 更新
保存工程副本。原远程仓库 Refresh Remote → AluDIY Designer → Update；面板显示 0.1.15-alpha，无需手工卸载。ZIP只是备用。

## 截面小窗
- 选择型材，在左/右视窗的截面小窗中，鼠标靠近槽口圆点或旁边编号会预高亮。单击选中槽位，沿杆槽轨一起高亮。选择范围大于圆点，不要求逐像素点中。
- 小窗内 **用于吸附** 固定这个槽轨为定位目标；**清除目标** 恢复普通吸附。选槽本身不修改已固定的目标，不自动创建关联。创建/解除关联仍使用已有的多选命令。
- 截面旋转后，选择区域和示意图使用同一套坐标；不会把原位置当成新槽位。双槽分别有稳定ID，封闭面不能选出不存在的槽。
- 点击小窗空白处或使用Shift/Ctrl点击，都不穿透改变模型选择。多选仍完整保留；小窗显示当前检查的那一根型材。
- G/连续画线操作中小窗暂时只读，鼠标在小窗上时暂停模型输入，移回模型区后继续。Esc/右键仍能取消/结束；避免把点击小窗误解为工程坐标。
- 布局按Blender有效DPI缩放并避让侧栏。视窗太窄/太矮时隐藏小窗，不保留不可见点击区；收起N侧栏或增大视窗后恢复。

## 顶部长度信息
N → AluDIY最顶部“设置双视窗工作区”所在方框内，按钮上方显示“当前选择”。
- 单选显示型材编号、截面外廓尺寸和设计线长度（mm）。这是只读实测值，不是长度输入框，也不是加工切割长度。
- 多选显示去重后的杆件/节点数量，明确当前查看杆件的长度；展开“各杆件长度”查看各根数值，不把当前长度冒充整组总长。
- 选具体杆端时标注起端/终端并显示所属杆件长度；单选独立节点显示节点坐标。
- G端点预览时，顶部长度随候选工程实时变化，取消恢复。画线保留视窗动态输入并增加“正在绘制”预览长度。
- 线视窗不再常驻绘制蓝色参考尺寸、两端引出线和静态节点坐标浮窗。起终端渐变、多选描边、关联提示和当前槽轨保留；同一检查槽与固定目标槽不重复画两次。

## 快速验收
1. 选一根2040，直接点击截面图同一面的两条槽：编号和轨道切换；无需在菜单找槽位。
2. 点击“用于吸附”，再选其他杆端G定位；确认后仍独立。已有手动关联创建/解除行为不变。
3. 多选两根，检查顶部数量和可展开长度；点槽位不会取消多选。模型上不再叠加蓝色尺寸线。
4. 选杆端G→Z→100，观察顶部长度预览并Esc取消；画线数值输入、轴锁、吸附继续正常。

## 兼容与边界
不更改工程schema；继续读取0.1/0.2/0.3格式及原槽轨关系。含槽轨关系的工程仍不要用0.1.13或更旧插件覆盖。
本版只调整UI，不增加槽轨滑移、真实接头、退让或制造校验。Windows、显示缩放、第三方插件和大型工程仍待本机体验确认。
