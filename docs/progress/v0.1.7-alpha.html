03 · 选择连接行为

保持连接 / 断开此杆端

保持连接会带动公共点处相连杆端；断开只修改所选杆件的这一端。左右视图始终同步。

Esc 取消 · Ctrl Z 撤销

本轮先验收这五件事

操作应看到的结果
立柱顶部 → 保持连接 → G Z 100公共点升高100，横梁近端跟随、远端不动；两侧实时预览。
撤销 → 断开此杆端 → G Z 100只延长立柱，原交点和两根横梁不动。
拖动中 Esc；确认后 Ctrl Z取消不留新节点；撤销同时恢复位置与连接关系。
多选相连杆件 → G共享节点不叠加位移；普通对象混选时给出提示。
仅选普通 Cube → G原生移动保持不变，不写 AluDIY 工程数据。
注意：保持连接不等于自动保持框架水平、正交或刚性。要整体抬高上层框架，请选择上层全部相关节点／杆件。位置吸附不会自动焊接节点。
