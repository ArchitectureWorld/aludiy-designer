范围与兼容

第一阶段只支持平端正交几何，三向要求三个设计端点重合。无斜切、45°拼角、偏置三向和真实连接件。局部矩形外廓检查不是全模型碰撞或承载认证。

工程格式不新增；交接规则继续采用 schema 0.4.0。先保存副本，不能用 0.1.15 或更早版本覆盖 0.4 工程。更新方式仍为 Refresh Remote → Update，无需卸载。

状态口径与验证

自动化、Blender 原生界面、旧功能回归、保存重开、覆盖安装及公网包验证分开记录。运行检查包含键鼠事件、命令和数据断言，不等于同数量独立人工验收。详见交付包 VERIFICATION.md；Windows、其他插件、多操作系统窗口和大型工程仍需体验验证。
