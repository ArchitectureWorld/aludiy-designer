批量换型选几根，改几根

保持节点、长度、完整多选集合；目标规格不改变下一根新画杆件的默认类型。

截面旋转±90° / 绝对角度

绕每根自身设计轴线调整长短边与槽口朝向。支持角度算式，不接受长度单位。

槽位检查稳定 ID · 只读高亮

二维截面与三维沿杆轨道同时提示。尚不是槽轨吸附、连接件兼容或制造验证。

三项快速验收

01 / 两根一起换成20×40，再旋转90°

两根实体都改变；设计轴线、节点、关联与选择数量不变。Ctrl+Z整体恢复本次角度。

02 / 同面两槽与封闭面

选单根六槽型材，依次检查同一面的两个槽。换成三槽型材后不再显示封闭面的槽，旧检查状态清除。

03 / 保存重开与原编辑链路

BOX/细节切换保留多选；保存重开后规格角度不丢失。原有G、吸附、锁轴、手动关联、连续画线继续测试。
