这一轮重点验收

01 / 断开后接回，再拖一次

先选分离杆端，G 靠近原节点。看到绿色“确认后连接”后确认，再移动这个公共节点，检查关联杆件一起变化。

02 / Ctrl 自由放置与地面定位

先 G，再按住 Ctrl，提示变为自由移动；松开应立即恢复吸附。将悬空立柱底端沿 Z 移到地面，蓝色提示仅定位。地面标高可在主面板修改。

03 / 取消、撤销和保存重开

连接预览中 Esc 不留下新关联；确认后 Ctrl+Z 恢复原关系；保存并重开仍可联动。输入精确数字优先，不应被吸附修改为别的距离。
