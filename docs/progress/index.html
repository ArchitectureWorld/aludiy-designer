三项快速验收

01 / 删除主杆，再移动原附着端

不手动停止定位，工程删除后直接G→X→100。删除撤销恢复原杆件与关系。

02 / 整组复制，不动原框架

同时选择主杆和横梁，Shift+D→Y→300。副本内部仍有关联，原件不动；Esc取消复制无残留，确认后一次撤销。

03 / 中键轻点与拖动

轻点打开，拖动只旋转。盘外点击不丢失多选；复制、删除确认、解除关联均用原工程命令。

工程数据版本不变：继续读取0.1/0.2/0.3/0.4。含0.4交接规则的工程不要降级到0.1.15或更旧版本覆盖。验证记录区分自动断言、真实Blender输入与Windows用户体验，不将测试数量当作全场景保证。
