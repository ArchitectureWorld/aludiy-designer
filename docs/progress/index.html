三项主要验收

01 / 原 Layout 保留，不再累积 .001

从普通 Layout 点设置，自动进入 ALU DIY。重复点击或返回原 Layout 后再点，工作区与三维区域数量不增长。

02 / 透视、正交与缩放都同步

分别从两侧切换小键盘5、旋转、缩放；完全同步模式下结果一致。“方向与中心”仍可独立缩放，“关闭”仍独立观察。

03 / 保存重开，无需手动再切一下

重开工程后立即对齐，原有多选移动、画线、换型及关联继续测试。

自动化测试与真实 Blender 运行日志随发布保留；核对对应源码 SHA 和公开更新源后才能视为上线。旧工程不会因为此次更新被删除。没有将槽位检查表述为物理接口或结构安全已验证。
