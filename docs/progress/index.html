解除槽轨关联：现在怎么操作

选主杆 · 点击对应槽→查看“此槽关联 N 处”→解除此槽关联 · 确认→选原附着端 · G 移动

只解除这一主杆/槽位，其他槽、其他约束和几何位置保留。只想解除一端，选该杆端后用“解除所选”。

停止定位：恢复普通吸附，关联仍在。解除关联：移除位置约束。清除交接：移除实体退让规则。取消/撤销能恢复对应数据。

L / T 交接：第一条完整流程

吸附摆好两根正交杆件→最后选择主杆→设置端面间隙→设置 / 更新 L·T 交接

入口位于侧栏“交接与端面退让”。设计线保持原位；顶部同时显示设计长度与实体参考长度。正退让缩短，负退让补长。

本测试截面示例：500 → 480 mm

主杆2040的U40方向朝向支杆，支杆设计长500mm；退让到距轴20mm的主杆面后为480mm，另设2mm间隙则478mm。不能仅凭型号名称推断朝向。L端主杆补长由支杆截面厚度计算。

调整后不再满足直角交接怎么办？

G不会因此被卡住。保留规则并提示“交接待处理”，整份工程暂停退让显示，禁止导出加工参考清单。调整回合法位置或清除规则后恢复；不偷偷删除规则或冒充已经校验。

三项验收

01 / 关联后停止定位，再真正解除

停止定位明确保留关联；解除此槽确认后原附着端立即G可动，其他槽关联保留。一次Undo/Redo恢复/解除对应关系。

02 / T交接：设计线不动，实体退到主杆面

先选支杆，最后选主杆；设置0和2mm间隙，核对顶部长度和右侧实体端面，再验证撤销。

03 / L交接、待处理与保存重开

L主杆补长，支杆退让。自由调整无位置关联的端点不被加工规则阻止；不合法交接应提示待处理且禁止导出。保存重开保持结果。
