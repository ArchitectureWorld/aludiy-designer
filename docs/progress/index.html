本版操作变化

已有工程＋插入矩形样例→原有杆件 + 新增 4 根

按钮改名为 插入矩形样例。样例以 3D 游标为起点，位于世界 XY 平面。不改变旧杆件，不把重合点自动焊接。连续插入会继续增加独立框架，重复使用同一位置可能产生重叠。

Ctrl + Z 撤销本次插入；新建空白项目 是独立清空操作，有内容时先弹确认。普通 Blender 对象不属于清空范围。

旧版已经覆盖、且撤销历史与备份都不存在的数据，更新插件不能凭空恢复。升级前请保存仍有效的工程副本。

备用安装 ZIP自动验证记录

日常升级：Blender 获取扩展 → Refresh Remote → AluDIY → Update。无需将 ZIP 测试作为发布前置步骤。

下一步的验收目标

01 / 画线和 G 移动使用同一套吸附反馈

鼠标接近目标时，明确显示节点 / 端点 / 中点 / 垂足 / 轴线位置、目标杆件和候选状态。轴锁定时不得吸附到轴外。

02 / 吸附定位与建立连接分开表达

落到同一坐标不自动宣称已连接。已有节点的复用或合并必须明确；中点 / 轴线位置暂不假装已经完成 T 型节点求解。

03 / 再接节点退让，不提前堆商业功能

先稳定定位、连接关系、撤销、保存；随后进入 L / T 节点与自动退让。商城、AI 与完整结构计算不抢占本轮。
