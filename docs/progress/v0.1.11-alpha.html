验收重点

01 / 从横梁中点直接画立柱

XY后备定位面在地上，仍能选到高位横梁中点；Z→300→Enter生成正确高度的立柱。旧杆件完整保留。

02 / 垂足与临时自由定位

确定起点后，靠近目标杆身的垂足；Ctrl按住/松开即时切换。Tab切换目标，显式轴/平面锁定不被候选破坏。

03 / 手动关联后才跟随

新画杆件独立；多选主杆和新杆创建关联后，主杆移动才驱动附着端。保存重开、取消及撤销继续验证。

验证：202项自动化测试；36项新画线运行检查 + 72项既有移动/关联/样例检查，另有后台与新进程重开。发布状态以公网索引和对应提交的CI结果为准。
当前定位的是设计轴线，不是制造级槽口或外表面。未包含任意表面吸附、自动退让、连接件、结构安全验证；Windows与复杂场景仍待本机验收。
