# AluDIY Designer v0.1.6-alpha 精确修改与远程更新设计

## 目标

在 v0.1.5-alpha 的线驱动建模基础上，补齐“已建构件可精确修改”的最小闭环，并发布首个可通过 Blender 远程扩展仓库更新的版本。

## 用户体验

### 选中型材

线图或实体任一侧选中型材后：

- 左侧显示该型材的临时参考尺寸；
- N 面板显示系统长度、起点坐标、终点坐标；
- 可按固定起端、固定末端或固定中心修改长度；
- 可分别编辑起点或终点的 XYZ；
- 可输入 XYZ 增量平移整根型材。

### 选中节点

在线图视窗选择节点后：

- N 面板显示节点 ID 和 XYZ；
- 可输入精确 XYZ 修改节点；
- 连接该节点的所有型材同步变化；
- 右侧实体和左侧工程线同步重建。

### 修改传播

节点是权威连接关系。移动共享节点时，不复制或拆分节点；所有引用该节点的杆件随之更新。被影响杆件的 revision 均递增。

### 参考尺寸与驱动修改

- 视口中的尺寸为临时参考尺寸，不作为持久约束写入工程数据；
- N 面板的长度／坐标输入是驱动修改；
- 持久 Dimension / Constraint 对象留到后续版本。

## 工程内核

新增：

- `GeometryChangeResult(moved_node_ids, affected_member_ids)`；
- `move_node(project, node_id, position_mm)`；
- `translate_member(project, member_id, delta_mm)`；
- `resize_member(...) -> GeometryChangeResult`，并正确递增所有受共享节点影响的杆件 revision。

任何修改后必须通过 `Project.validate()`；零长度结果被拒绝，且调用方在写回场景前保留原工程状态。

## Blender 适配

新增操作符：

- `aludiy.edit_active_node`；
- `aludiy.edit_member_endpoint`；
- `aludiy.translate_active_member`。

现有 `aludiy.resize_active_member` 继续作为长度驱动入口。

操作符采用字符串输入，复用 `parse_distance_mm`，支持 `1200`、`1.2m`、`600+20` 和负值坐标／位移。所有工程修改操作均带 `UNDO`。

## 临时尺寸叠加层

仅在线图视窗显示：

- 选中 Member：尺寸线、端部引线、长度标签；
- 选中 Node：坐标标签；
- 不改变工程数据；
- 投影失败或对象不可见时安全跳过。

## 远程更新

- Extension ID 保持 `aludiy_designer`；
- Manifest 版本更新为 `0.1.6`；
- 运行时显示 `0.1.6-alpha`；
- 构建包名从 Manifest 动态生成；
- 标签 `v0.1.6-alpha` 触发 Release 与 GitHub Pages；
- 页面部署后仓库地址为 `https://architectureworld.github.io/aludiy-designer/index.json`。

## 第一稿不包含

- 视口尺寸文字直接点击编辑；
- 持久尺寸和约束求解器；
- 节点拖拽 Gizmo；
- L/T 节点、退让和连接件；
- 自动结构校核。

## 验收

1. 将 1200 mm 杆件改为 1500 mm，三种固定方式结果正确；
2. 编辑共享节点坐标后，所有相邻杆件联动；
3. 平移型材后，其两个端点移动，连接构件同步变化；
4. 左侧显示选中型材临时尺寸或节点坐标；
5. 保存／重开后修改结果一致；
6. 单元测试、静态契约、确定性构建通过；
7. 分支合并并创建发布标签后，GitHub Pages 生成远程仓库索引。
